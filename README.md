# GT Detail — сайт для GitHub Pages

Отдельная копия чёрно-белого шаблона для студии GT Detail в Абакане. Исходный сайт carservice124 и шаблон в соседних папках не изменены. Репозиторий: [archRDS/GT-Detail](https://github.com/archRDS/GT-Detail).

## Публикация

Файлы сайта лежат в корне репозитория: `index.html`, `config.js`, `app.js`, CSS-файлы, `hero-photo.png` и `.nojekyll`. Для публикации в настройках репозитория откройте **Settings → Pages** и выберите **Deploy from a branch → main → /(root)**. Сборка и установка пакетов не нужны.

## Локальный просмотр

Из этой папки запустите `node server.mjs`. Сайт откроется по адресу <http://localhost:4175/>. Для остановки сервера нажмите `Ctrl+C`.

## Источник данных

Данные взяты из [карточки GT Detail в 2ГИС](https://2gis.ru/abakan/firm/70000001067761418) 24.10.2026: название, адрес, телефон, режим работы, рубрики, сведения об услугах и [отзывы](https://2gis.ru/abakan/firm/70000001067761418/tab/reviews). В карточке указано, что компания давно не обновляла данные. Перед отправкой владельцу стоит подтвердить контакты и режим работы.

В [разделе цен 2ГИС](https://2gis.ru/abakan/firm/70000001067761418/tab/menu) нет числового прайса. Поэтому на сайте указано «По запросу» без придуманных сумм. Услуги детейлинга, перечисленные в карточке и отзывах, стоит подтвердить у студии.

Форма готовит сообщение в WhatsApp по номеру из 2ГИС. Посетитель сам отправляет сообщение, после чего студия подтверждает дату и время. Сайт не хранит заявки и не бронирует интервалы автоматически.
